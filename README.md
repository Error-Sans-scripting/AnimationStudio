# Animation Studio — исходный код

Мобильный редактор анимации с чёрно-фиолетовым интерфейсом. Здесь нет встроенных декоративных изображений, логотипов или аватарок. Значки инструментов сделаны встроенными SVG-векторами прямо в HTML, поэтому отдельные файлы картинок не нужны.

## Запуск в браузере
1. Установите Node.js LTS.
2. Откройте терминал в папке проекта.
3. Выполните `npm install`.
4. Выполните `npm run start`.
5. Откройте адрес, который покажет Vite.

## Сборка Android
1. Установите Android Studio и Android SDK.
2. Выполните `npm install`.
3. Выполните `npm run build`.
4. Один раз выполните `npx cap add android`.
5. Выполните `npx cap sync android`.
6. Выполните `npx cap open android`, затем соберите APK в Android Studio.

## Возможности текущей версии
- Рисование кистью, ластиком, линиями, прямоугольниками, эллипсами и текстом.
- Слои и управление видимостью.
- Таймлайн: добавление, дублирование и удаление кадров.
- Просмотр анимации и луковая кожа.
- Цвет, размер кисти, непрозрачность, эффекты свечения/тени/мягкости.
- Импорт изображения пользователем.
- Сохранение и открытие `.anproj`, экспорт PNG и WebM.
- Манифест PWA и service worker.

Это исходный проект для дальнейшей разработки, не готовый APK и не полная замена профессиональному редактору анимации. Риггинг, аудиодорожки, tween-анимация и маски пока не реализованы.
