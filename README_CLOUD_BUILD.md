# Сборка APK без собственного компьютера

Этот архив содержит исходники редактора и workflow для облачной сборки Android APK через GitHub Actions.

## Важно
- Это исходный проект, а не уже собранный APK.
- Для облачной сборки понадобится аккаунт GitHub и создать репозиторий, загрузив в него файлы и папку `.github/workflows` из архива.
- После загрузки файлов откройте вкладку **Actions**, выберите **Build Android APK** и нажмите **Run workflow** (если workflow не стартовал автоматически после push).
- Когда сборка закончится успешно, откройте запуск workflow, прокрутите вниз до **Artifacts** и скачайте `animation-studio-debug-apk`. Внутри будет `app-debug.apk`.
- Если GitHub показывает ограничения/ошибку, не публикуйте пароль или токены в чате; пришлите только текст ошибки.

Папку `.github` важно загрузить вместе с остальными файлами. Если интерфейс GitHub на телефоне не позволяет загрузить папку, потребуется способ загрузить структуру репозитория целиком, например через мобильный браузер в режиме «Версия для ПК» или веб-IDE.
